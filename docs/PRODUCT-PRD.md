# 产品需求文档（PRD）对齐说明

> 外部 PRD 产品名「智学伴家」仅作需求来源；本仓库项目名称保持 **家庭规划**，功能按 PRD 演进。

## 一、产品定位（PRD → 本项目）

| PRD 概念 | 本项目映射 |
|----------|------------|
| 飞书任务 → 家庭任务看板 | `/tasks` 双区任务栏 + `/assign` 分发 |
| 飞书审批 → 提交与验收 | 作业「提交验收」→ 家长审批待办 → 通过发积分 / 打回重做 |
| 多维表格 → 学情仪表盘 | **二期**：周/月看板、雷达图 |
| 智能助手 → AI 管家 | **二期/三期**：截图导入、AI 批改、日结周报 |

**愿景**：把家长的催促转化为客观记录与正向激励，培养孩子目标管理与自我驱动。

## 二、角色与权限

| PRD 角色 | 系统枚举 | 当前能力 |
|----------|----------|----------|
| 超级管理员（家长 A） | `SUPER_ADMIN` | 创建家庭、邀请成员、设置任务奖励积分 |
| 管理员（家长 B/长辈/家教） | `ADMIN` | 分发任务、验收、查看团队 |
| 执行者（孩子） | `EXECUTOR` | 执行任务、提交验收、记录心情、积累积分 |
| AI 助手 | — | **Roadmap 二期** |

## 三、演进路线

### 一期 MVP（当前迭代目标）✅ 进行中

- [x] 家长派发 → 孩子打卡 → 家长验收闭环
- [x] 学科标签、任务积分奖励
- [x] 提交时记录心情
- [x] 验收通过发放积分 / 打回重做
- [x] 基础专注计时（番茄钟，使用任务预估时长）
- [ ] 基础积分商城（兑换申请）— 下一迭代

### 二期 AI 效率版

- 钉钉/微信作业截图一键导入
- AI 静默预批改 + 辅导话术
- 每日 AI 总结（21:30）

### 三期 生态版

- 苏格拉底 AI 小导师
- 错题本与重组卷
- 家庭周会投屏、IoT 联动
